SF Finance nasceu da imersão que participei da Alura em parceria com Google: Imersão Engenharia de Software: DEV na era da IA 
finalizada em 04/11/2026. 
Adaptei o exemplo da imersão para uma realidade pessoal de controle de finanças para a elaboração do prompt a ser submetido 
ao Google AI Studio e a partir do resultado sigo refinando e aprimorando o sistema criado.

Segue abaixo o prompt submetido. Para próximos passos, vou criar base de dados para o projeto e demais atividades já levantadas
para segunda versão, como geração de relatórios, gráficos...

PROMPT
Você é uma pessoa especialista em produtos digitais voltados para finanças pessoais.
Quero criar o S&F Finance, uma aplicação simples para ajudar na organização e controle de finanças pessoais.
A primeira versão deve permitir que a pessoa:
• cadastre manualmente receita e despesas;
• visualize os dados (despesas ou receita) cadastrados;
• edite um dado (despesa ou receita)cadastrado;
• exclua um dado (despesa ou receita) cadastrado;
• mantenha seus dados após atualizar a página.
Para cada dado (despesa ou receita), considere:
• título;
• descrição (opcional);
• data (vencimento para a despesa ou crédito para a receita);
• status.
Organize a resposta em:
1. problema que o aplicativo resolve;
2. público principal;
3. requisitos funcionais;
4. critérios que podemos utilizar para testar a primeira versão.
Não escreva código ainda.
